# Hockey Live Coder

A one-tap live coder for field hockey matches, made for a tablet held sideways.

- One tap records the team, the event, and its side or zone. The app adds the quarter.
- Every tap is saved on the tablet. It works with no signal once it has been added to the home screen and opened once.
- "Send file" shares the match as an XML file of coded events.

No match data is stored anywhere but on the tablet that coded it.
